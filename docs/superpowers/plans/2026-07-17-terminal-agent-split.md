# Terminal/Agent Split — Implementation Plan (Plan 1 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split `ai_sessions` into two independent subsystems — `terminal` and `agent` — each with its own schema, tables, id space, and status enum, neither referencing the other.

**Architecture:** The items platform's tables stay in `public` for now (Plan 2 moves them). This plan adds three schemas: `terminal`, `agent`, and the `core.workdirs` table that replaces `ai_workspaces`. The supervisor's persist/seq/replay logic is extracted to a `session-core` both drivers depend on; neither driver depends on the other. The `0000` baseline is regenerated by hand — the platform is unshipped, so it is born with schemas.

**Tech Stack:** apps/api (Fastify 5, `@fastify/websocket`, node-pty, `@anthropic-ai/claude-agent-sdk`), apps/web (React 19, TanStack Router/Query, xterm, vitest), packages/db (drizzle-orm + drizzle-kit, postgres-js), apps/eer (the model SSOT + conformance).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-17-schema-namespacing-and-ai-split-design.md`. Read it first.
- **Branch `ai-schema-split`**, worktree `.claude/worktrees/ai-schema-split`. Never touch `.claude/worktrees/items-platform` — another agent works there.
- One commit per task; conventional commits scoped by app (`feat(db):`, `fix(api):`).
- **The independence rule:** no FK, import, or type may cross `terminal` ↔ `agent` in either direction. Both may depend on `core`, `records`, and `session-core`. Task 10 enforces this with a test.
- **`drizzle-kit generate` is not schema-move aware** — it emits `DROP TABLE` + `CREATE TABLE` for a moved table. The baseline is hand-written and reviewed as SQL. Never trust generated output for a schema move.
- **The EER model is the SSOT.** `apps/eer/models/items-platform.json` drives conformance; drizzle must match it in both directions.
- Enum values, verbatim:
  - `terminal.session_status`: `starting | live | disconnected | exited | failed`
  - `agent.session_status`: `starting | running | idle | awaiting_input | interrupted | exited | failed`
  - `agent.permission_mode`: `default | acceptEdits | bypassPermissions | plan | dontAsk`
  - `agent.permission_status`: `pending | allowed | denied`
  - `core.runner_kind`: `local | container`
- **Dev DB for this branch: `tickets_split`** (isolated; never point at `tickets_platform` — that is the other agent's). Set `POSTGRES_DATABASE=tickets_split` in the worktree `.env`.
- Postgres: Docker `tickets-postgres-1` @ `127.0.0.1:5532`, user/password `postgres`.
- Checks: `pnpm typecheck` · `pnpm --filter @tickets/api test` · `pnpm --filter @tickets/web test` · `pnpm --filter @tickets/db test` · `pnpm --filter @tickets/eer test` · `pnpm build`.

- [ ] **Step 1: Write the failing test**

Append to `packages/db/src/schema/describe-schema.test.ts`:

```ts
import { pgSchema, pgTable, serial } from 'drizzle-orm/pg-core';

it('reports null schema for a public table and the name for a namespaced one', () => {
  const demo = pgSchema('demo');
  const publicTable = pgTable('plain', { id: serial('id').primaryKey() });
  const nsTable = demo.table('scoped', { id: serial('id').primaryKey() });

  const d = describeSchema({ publicTable, nsTable } as Record<string, unknown>);

  expect(d.tables.find((t) => t.name === 'plain')?.schema).toBeNull();
  expect(d.tables.find((t) => t.name === 'scoped')?.schema).toBe('demo');
});
```

- [ ] **Step 3: Implement**

```ts

const schema = cfg.schema ?? null;
```

Add `schema` to the returned table object and to its exported type.

```ts
it('no foreign key crosses terminal <-> agent in either direction', () => {
  const crossings: string[] = [];
  for (const table of allTables) {
    const cfg = getTableConfig(table);
    const from = cfg.schema ?? 'public';
    if (from !== 'terminal' && from !== 'agent') continue;
    const other = from === 'terminal' ? 'agent' : 'terminal';
    for (const fk of cfg.foreignKeys) {

      if (target === other) crossings.push(`${from}.${cfg.name} -> ${target}`);
    }
  }

});
```
