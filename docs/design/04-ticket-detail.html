tickets screen 04 — ticket detail: peek drawer + full page

One detail model, two containers. Drawer (light frame): a single scroll stack for triage — fields as a compact two-column grid, then description, subtasks, links, and a Comments/Activity segmented pane. Full page (dark frame): reading layout — prose, subtasks, links and comments in the main column; the per-type field form and the activity feed live in a right rail. Same components, re-flowed. Subtasks are real tickets: opening one swaps the header for a parent breadcrumb (small exhibit below).
