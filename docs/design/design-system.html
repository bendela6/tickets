tickets design system · v1 · for sign-off

Instrument — a quiet-industrial system for a tool you live in all day

Warm-tinted neutrals, borders before shadows, one indigo accent. IBM Plex Sans carries the UI; Plex Mono carries identity — ticket keys, project prefixes, token names. Status kinds are shape-coded as well as color-coded, so state reads without color. Every token below maps 1:1 to a Tailwind theme variable; light and dark are designed together.

IBM Plex Sans — UI IBM Plex Mono — keys & data 4px grid · radius 5/8/12 · WCAG AA both themes
