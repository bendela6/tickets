AI sessions — agents do real work on the board, and you can always see it

Three nouns, kept distinct everywhere: a Session is one live run — kind terminal (a real PTY, a screen) or agent (a structured run the app renders richly). An Agent is a reusable persona that is also a user — square avatar, AGENT badge, owns tickets, writes comments. A Workspace is the directory a session runs in. The headline: an agent session can dispatch other agents onto tickets, so the sessions list is a tree. Reuses Instrument tokens plus the Automations run-pill and Connections provider-card language; nine new components below, then screens A–G in light + dark, desktop + mobile. awaiting input is the system's only solid-fill pill — a run stopped on a human must be unmissable — and cost is never hidden.
