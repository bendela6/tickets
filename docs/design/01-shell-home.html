Shell shape: left sidebar. The workspace is project-plural — a sidebar gives every project a permanent, glanceable slot (with its own micro-progress), keeps the full top edge free for each screen's own toolbar (view tabs, filters), and collapses cleanly to a bottom tab bar on mobile. The current-user picker sits pinned at the bottom — always visible, since it decides attribution for every action. ⌘K opens the command palette from anywhere.
