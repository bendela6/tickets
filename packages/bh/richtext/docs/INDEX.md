## Rich text

- [Overview](../docs/overview.md): Rich text an app writes and stores as a document, edited with Tiptap and shown without it.
- [The core](../docs/core.md): The features an editor switches on, an app's own inline nodes, and markdown to a document and back, with no React.
- [RichTextEditor](../docs/editor.md): Writes rich text on a field's floor, holding a document and reporting each edit as its JSON.
- [The toolbar](../docs/toolbar.md): The controls an editor's features make, above its text, one tab stop with the arrows along it.
- [Suggestions](../docs/suggestions.md): What @, an app's own trigger and / offer at the caret, filled by the app, picked with the keys.
- [Images](../docs/image-upload.md): Images pasted, dropped or picked, each held in its place with its progress while the app uploads it.
- [The composer](../docs/composer.md): The editor as a comment box, its toolbar in a row under the text beside a submit button, and ⌘↩ to send.
