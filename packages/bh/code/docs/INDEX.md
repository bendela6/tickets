## Code

- [Overview](../docs/overview.md): Show a code fragment and write one, coloured the same way, from one syntax map.
- [CodeBlock](../docs/code-block.md): Shows a code fragment to read, its lines numbered and coloured by its language.
- [CodeEditor](../docs/code-editor.md): Writes code, from a script or a YAML file to TSX or markdown, coloured as a code block colours it, growing with its text.
- [ExamplePanel](../docs/example-panel.md): Show what a piece of code draws beside the code, to read, copy, resize and open full screen, and to edit with the app's own editor.
